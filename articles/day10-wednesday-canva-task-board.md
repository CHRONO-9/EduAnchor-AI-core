## 1. なぜ言葉で何度言っても提出物が出ないのか？

未提出の常習生徒は、怠けているのではなく「何から手をつけていいか段取りが組めない」「締切までの時間の見積もりができない（時間盲）」ケースが大半です。
黒板に「○日必着！」と文字だけで書いても、ワーキングメモリの弱い生徒や多重課題を抱える生徒には素通りされます。「ページ数の山を1日3ページに小分けした視覚的ゲージ」を提示することが打開の鍵です。

## 2. Canvaテンプレート×AI日割り逆算プロンプト

以下のプロンプトに提出物の総ページ数と締切日を入力すると、生徒が絶望しない「1日あたりのスモールステップ日割り表」が一瞬で計算されます。

### 【提出物日割り分解プロンプト】
```text
# 命令
以下の【提出物情報】から、勉強が苦手な生徒でも無理なく達成できる「日割りタスク表」を作成してください。

# 【提出物情報】
・対象教材: 数学ワーク（p.40〜p.60・計20ページ）
・提出締切: 11月20日（金）まで（残り7日間）
・土日の稼働: 平日より少し多め

# 制約
1. 1日のノルマを「大問3つ」または「2〜3ページ」に細分化。
2. 予備日（バッファ）を締切前日に必ず1日設けること。
3. できた日のマスに貼る「達成チェックシール風アイコン」を付与。
```

### 【入力実例】
```text
ワーク20ページ、残り7日間、水曜スタート。
```

### 【AIによる出力実例】
```text
・水曜: p.40〜42（基礎計算3ページ・所要15分）
・木曜: p.43〜45（基本問題3ページ・所要15分）
・金曜: p.46〜48（応用問題3ページ・所要20分）
・土曜: p.49〜52（まとめ4ページ）
・日曜: p.53〜56（章末問題4ページ）
・月曜: p.57〜60（仕上げ4ページ）
・火曜: 【完全予備日・やり残しリカバリーDAY】
・水曜朝: 提出完了！
```

## 4. やってはいけないNG指導と現場のリカバリー策

* **やってはいけないNG指導：未提出者の名前を黒板に貼り出して公開処刑する**  
  クラス全員の前で未提出者の名前を晒すと、生徒は恥ずかしさから「どうせ俺はダメだし」と反発・自暴自棄になり、提出率が上がるどころか教員への不信感と不登校の引き金になります。ペナルティではなく『達成の見える化』で動かしてください。

* **現場のリカバリー策：「未完成でも8割提出でOK」の減点救済ルール**  
  「100%完璧に解かないと出せない」と思い詰めて出せない完璧主義・フリーズ型の生徒には、「白紙が残ってても、今日やった分まで出せば提出点をつける」とハードルを下げてまず提出箱に入れさせます。
