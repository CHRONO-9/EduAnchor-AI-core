## 1. 支援情報は「待っているだけ」では当事者に届かない

自治体や福祉協議会には、就学援助、緊急小口資金、無料の食糧支援など多くのセーフティネットが存在します。
しかし、それらの案内文書は難解な行政用語・漢字だらけで、本当に支援を必要としている家庭（日本語が不自由な保護者、多重労働で余裕のないひとり親、軽度知的障害のある保護者）には届きません。
学校が配布するお便りに、**「スマホで申請できるQRコード」「全漢字ルビ」「やさしい日本語」**を施すだけで、救われる命と教育環境があります。

---

## 2. 行政文章を「やさしい日本語＆多言語」に一発変換するプロンプト

自治体の支援案内やお知らせの文章を入力するだけで、すべての家庭に届く配慮文書を生成します。

### 【やさしい日本語・福祉案内変換プロンプト】
```text
# 命令
以下の【行政支援テキスト】を、外国籍保護者や読解に困難を抱える保護者でも直感的に理解できる「やさしい日本語（全ルビ対応表記）」および「多言語（ポルトガル語・英語）」に翻訳・要約してください。

# 【行政支援テキスト】
[自治体の就学援助、冬季生活支援給付金、こども食堂・フードバンクの案内文を貼り付け]

# 制約
1. 難しい行政用語（「要件」「給付対象」「申請手続」など）を日常語に言い換える（「もらえる人」「もらいかた」）。
2. 「いつまでに」「どこに」「何を持っていけばいいか」を3行の箇条書きに整理。
3. 相談窓口の電話番号と、匿名で相談できるLINE相談窓口を明記。
```

### 【入力実例】
```text
高校等就学支援金および年末緊急生活支援給付金の案内。
```

### 【AIによる出力実例】
```text
【やさしい日本語】
「冬休（ふゆやす）みの お金（かね）の 支援（しえん）の お知（し）らせ」
お金（かね）に 困（こま）っている 家（いえ）へ、生活（せいかつ）の お金（かね）を 助（たす）ける 制度（せいど）が あります。
・もらえる人: 高校生（こうこうせい）がいる ひとり親（おや）の 家庭（かてい）など
・すること: スマホから QRコードを 読（よ）んで 申（もう）し込（こ）む
・わからない時: 学校（がっこう）の 相談窓口（そうだんまどぐち）へ 電話（でんわ）してください。秘密（ひみつ）は 守（まも）ります。
```

## 3. 終業式前の配布・掲示ステップ

* **お便りの印刷・配布: 終業式の1週間前、全校生徒に「冬休みの過ごし方」とセットで全員に配布（特定の生徒だけではないためプライバシー保護）。
* **保健室・相談室前の掲示: 生徒が人目を気にせず持ち帰れるよう、相談窓口のミニカードを相談室前に設置。
* **保護者連絡アプリ配信: スマホ翻訳機能が使えるよう、テキスト形式でも保護者アプリに配信。

## 4. やってはいけないNG指導と現場のリカバリー策

* **やってはいけないNG指導：困窮していると思われる生徒だけを呼んで手渡しする**  
  「君の家は大変そうだからこれ持って帰りなさい」と特定の生徒だけに支援プリントを渡すと、生徒は惨めさと恥ずかしさで深く傷つき、プリントを捨ててしまいます。必ず『全校配布・全員周知』の形式を取り、家庭のプライバシーを死守してください。

* **現場のリカバリー策：スクールソーシャルワーカー（SSW）との即時連携**  
  生徒から「実は家でご飯が食べられない」「電気を止められた」とSOSがあった場合は、担任が一人で抱え込まず、即日スクールソーシャルワーカーと管理職に報告し、自治体福祉課と緊急連携するフローを徹底します。
