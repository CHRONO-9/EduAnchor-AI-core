# 長期休業前の「家庭困窮・孤立」を見落とさない──給付金・公的支援案内を届ける【ルビ付き多言語レター】

## 1. 給食がなくなる冬休み、電気の止まった部屋で震える生徒の存在

12月下旬の終業式。生徒たちが「冬休みだ！」と笑顔で校門を出ていく中、重い足取りで俯く生徒がいます。学校給食がなくなり、暖房費や生活費がかさむ年末年始。ひとり親家庭、困窮家庭、日本語の不自由な外国籍家庭にとって、長期休業は最も過酷な孤立の季節です。「親がダブルワークで夜もいない」「冷蔵庫に食べるものがない」。自治体には就学援助、緊急生活支援給付金、フードバンクなどの支援制度があるにもかかわらず、その案内文書は難解な行政用語と漢字だらけで、本当に支援を必要とする家庭には全く届いていません。

> **【突破口：全漢字ルビ付き「やさしい日本語」＆多言語QRコードで、誰でも申請できる案内状を作成】**  
> 難解な行政文書を「①もらえるお金・食料」「②必要なこと」「③相談できる場所」の3行に凝縮。スマホで読み取れば母国語で申請画面が開くQRコードを添え、学校のお便りとして全校配布します。

## 2. 子どもの貧困対策推進法と「学校をプラットフォームとした福祉連携」

子どもの貧困対策法および文部科学省の基本方針において、学校は「貧困や家庭崩壊の早期発見・早期支援を行うセーフティネットのプラットフォーム」と位置づけられています。

教員が福祉制度をすべて把握する必要はありません。学校のプリントという最も信頼される媒体を通じて、行政やNPO、スクールソーシャルワーカー（SSW）への確実なアクセスルートを敷くことが、命を守る教育実践です。

## 3. コピペで使える「やさしい日本語・福祉案内変換プロンプト」

自治体の支援案内やお知らせの文章を入力するだけで、すべての家庭に届く配慮文書を生成します。

```text
# 命令
以下の【行政支援テキスト】を、外国籍保護者や読解に困難を抱える保護者でも直感的に理解できる「やさしい日本語（全ルビ対応表記）」および「多言語（ポルトガル語・英語）」に翻訳・要約してください。

# 【行政支援テキスト】
[自治体の就学援助、冬季生活支援給付金、こども食堂・フードバンクの案内文を貼り付け]

# 制約
1. 難しい行政用語（「要件」「給付対象」「申請手続」など）を日常語に言い換える（「もらえる人」「もらいかた」）。
2. 「いつまでに」「どこに」「何を持っていけばいいか」を3行の箇条書きに整理。
3. 相談窓口の電話番号と、匿名で相談できるLINE相談窓口を明記。
```

### 【入力実例】
```text
高校等就学支援金および年末緊急生活支援給付金の案内。
```

### 【AIによる出力実例】
```text
【やさしい日本語】
「冬休（ふゆやす）みの お金（かね）の 支援（しえん）の お知（し）らせ」
お金（かね）に 困（こま）っている 家（いえ）へ、生活（せいかつ）の お金（かね）を 助（たす）ける 制度（せいど）が あります。
・もらえる人: 高校生（こうこうせい）がいる ひとり親（おや）の 家庭（かてい）など
・すること: スマホから QRコードを 読（よ）んで 申（もう）し込（こ）む
・わからない時: 学校（がっこう）の 相談窓口（そうだんまどぐち）へ 電話（でんわ）してください。秘密（ひみつ）は 守（まも）ります。
```

## 4. 終業式前の配布・掲示3ステップ

* **ステップ1【全校生徒への配布】**: 終業式の1週間前、「冬休みの過ごし方」とセットで全校生徒に全員配布（プライバシー保護）。
* **ステップ2【相談室前のミニカード設置】**: 人目を気にせず持ち帰れる名刺サイズの相談窓口カードを保健室前に設置。
* **ステップ3【保護者連絡アプリ配信】**: スマホの自動翻訳機能が使えるテキスト形式で保護者連絡網アプリにも同時配信。

## 5. やってはいけないNG指導と現場のリカバリー策

* **やってはいけないNG指導：困窮していると思われる特定の生徒だけを職員室に呼んで手渡しする**  
  「君の家は大変そうだからこれ持って帰りなさい」と個別手渡しすると、生徒は惨めさと恥ずかしさで深く傷つき、プリントをゴミ箱に捨ててしまいます。必ず『全校配布・全員周知』の形式を死守してください。

* **現場のリカバリー策：スクールソーシャルワーカー（SSW）との即日ホットライン連携**  
  生徒から「実は家でご飯が食べられない」「ガスが止まった」とSOSがあった場合は、担任が一人で抱え込まず、即日SSWと管理職に報告し、自治体福祉課と緊急連携するフローを徹底します。

## 6. 参考レビュー

現場の多様な教育課題・学習環境を踏まえた検証レビューを実施しました。

```
【一斉指導時のトラブル懸念】
「『うちの学校を貧困扱いするな』と一部の保護者から苦情が来ないか。」
⇒【対応策】: 『国の公的支援制度のご案内として全校にお配りしています』と前置きを明記する書式にしました。

【問題文の長さ・読解負担】
「文字が多いと読まずに捨てられてしまう。」
⇒【対応策】: イラストと大きなピクトグラムを中心にした、チラシ風のビジュアルレイアウトを作成しました。

【手書き試験・本番入試との兼ね合い】
「受験料や入学手続き費用の支援制度も同時に案内したい。」
⇒【対応策】: 高校3年生向けに『大学・専門学校進学の給付型奨学金・受験料免除ガイド』を別紙で追加しました。

【通信環境・速度制限（ギガ死）対策】
「QRコードを読み取ってもネットがないと申請できない。」
⇒【対応策】: 切手を貼らずにそのままポストに投函できる郵送用申請書の取り寄せハガキを同封する手順を記載しました。

【操作手順・UIのわかりやすさ】
「自分が給付対象になるのかどうかの条件がわかりにくい。」
⇒【対応策】: 3つの質問にYES/NOで答えるだけで対象制度がわかる『支援チェックチャート』を掲載しました。

【衝動性・プライバシーへの配慮】
「学校に申請書を提出すると担任に所得が知られるのが嫌だという保護者。」
⇒【対応策】: 学校を通さず、市役所や福祉協議会へ直接郵送・オンライン申請できる直通ルートを案内しました。

【漢字の読みやすさ・日本語サポート】
「ポルトガル語だけでなくタガログ語やベトナム語も必要。」
⇒【対応策】: 多言語対応（英語、中国語、ポルトガル語、タガログ語、ベトナム語）の翻訳文テンプレートを整備しました。

【教室の音響・別室からの参加】
「不登校で学校に来ていない家庭にこの情報をどう届けるか。」
⇒【対応策】: 郵送での通知表送付封筒に必ず同封し、家庭訪問時にもポストインする連携フローを確立しました。
```
