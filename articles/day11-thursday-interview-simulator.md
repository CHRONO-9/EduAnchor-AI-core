## 1. 丸暗記した志望理由は、最初の「変化球」で崩壊する

多くの高校生は、事前に作った台本を一言一句丸暗記して面接に臨みます。しかし面接官は「暗記スピーチ」を聞きたいのではありません。
「もし希望の部署・学部に配属されなかったらどうしますか？」「最近気になったニュースは？」「短所を友人から指摘された経験は？」といった変化球を投げられた瞬間、暗記が吹き飛んで沈黙し、不合格になります。必要なのは『アドリブでの3秒復帰力』です。

---

## 2. 音声対話で無限に練習できるAI面接官プロンプト

ChatGPTやスマホの音声対話モードでこのプロンプトを起動すると、AIがリアルな面接官になりきり、1問ずつ質問を投げかけてくれます。

### 【AI模擬面接官ロールプレイプロンプト】
```text
# 命令
あなたは[専門学校 / 大学推薦入試 / 製造業の高卒採用]の厳格かつ温かい面接官です。
私（高校3年生）に対して、模擬面接を実施してください。

# ルール
1. 一度に複数の質問をせず、必ず1問ずつ質問すること。
2. 私の回答が終わったら、短く相づちを打ち、深掘り質問または変化球質問（「なぜそう思う？」「具体例は？」）を投げかけること。
3. 全5問が終わったら、以下の3観点でフィードバックを行うこと。
   ・良かった点（具体性・熱意）
   ・改善点（結論ファースト・話し言葉の修正）
   ・変化球質問への合格回答モデル案

# 最初の質問
「それではまず、本校（弊社）を志望した理由を1分程度でお話しください。」からスタートしてください。
```

### 【入力実例】
```text
生徒がスマホの音声マイクに向かって「私が御社を志望したのは、小さい頃からモノづくりが好きで…」と回答。
```

### 【AIによる出力実例】
```text
AI面接官: 「モノづくりへの興味、よく伝わりました。では具体的に、高校生活の中で『自分で工夫して何かを形にした経験』があれば教えていただけますか？失敗したエピソードでも構いませんよ。」
```

## 3. 放課後15分のセルフ面接トレーニング手順

* **プロンプト起動: スマホの音声入力アプリまたはPCでプロンプトを入力。
* **5問の模擬面接（約8分）: 椅子に背筋を伸ばして座り、声に出して回答。
* **フィードバック確認（約5分）: AIが指摘した「抽象的すぎる箇所」「語尾の癖」をメモし、言い直して終了。

## 4. やってはいけないNG指導と現場のリカバリー策

* **やってはいけないNG指導：難しいビジネス用語を無理に喋らせる**  
  高校生の面接で面接官が見ているのは、難しいカタカナ語の知識ではなく「素直さ・挨拶・元気・人の話をしっかり聞く態度」です。「コンセンサス」「SDGsの観点から」など中身の伴わない背伸びをさせると、突っ込まれた際に自爆します。

* **現場のリカバリー策：「3秒の沈黙は堂々と置いていい」と教える**  
  予期せぬ質問をされたら、「少し考える時間をいただいてもよろしいでしょうか」と堂々と言って5秒呼吸を整える練習をさせます。これだけで「落ち着いて誠実に対応できる生徒」と高評価に変わります。
