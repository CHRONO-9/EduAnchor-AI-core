## 1. 専門外顧問を苦しめる「冬の部活3重苦」

冬の部活動は、夏と同じメニューをやると重大な事故につながります。
1. **日照時間の激減**: 放課後の練習時間は実質40〜50分。ダラダラ走らせる時間はない。
2. **気温低下と怪我リスク**: ウォーミングアップ不足による肉離れ、関節の痛みが頻発。
3. **モチベーションの低下**: オフシーズンで公式戦がなく、生徒の目標意識が希薄化。
これらを解決するのは「科学的な高密度インターバルトレーニング（HIIT）とゲーム感覚のアジリティ設計」です。

## 2. 種目・天候・場所別 練習メニュー自動生成プロンプト

以下のプロンプトに部活名と活動環境を入れるだけで、スポーツ科学に基づいた45分完結メニューが生成されます。

### 【冬期部活45分メニュー生成プロンプト】
```text
# 命令
以下の【部活動条件】に基づき、冬期の怪我を防止しながらパフォーマンスを向上させる「45分間完結の練習メニュー」を作成してください。

# 【部活動条件】
・部活名: [例: サッカー部 / バスケットボール部 / 卓球部]
・活動場所: [例: 雨天時の渡り廊下 / 暗いグラウンドの隅 / 半面体育館]
・生徒数: [例: 20名（男女合同）]
・時間: 計45分（完全下校時刻厳守）

# メニュー構成の制約
1. 動的ストレッチ＆体温上昇（8分）: 静的ストレッチではなく動的動作で心拍数を上げる。
2. アジリティ・神経系トレーニング（12分）: ラダーやステップを用いた俊敏性強化。
3. 種目特有のスキルサーキット（15分）: 狭い場所でもボールや道具に触れる工夫。
4. クールダウン＆怪我セルフチェック（10分）: 痛みのある部位の確認と記録。
```

### 【入力実例】
```text
野球部、照明のないグラウンド脇のスペース、15名、45分。
```

### 【AIによる出力実例】
```text
8分ブラジル体操＋12分変則ダッシュ（合図反応ドリル）＋15分テニスボール捕球ペアドリル＋10分ペア肩甲骨・股関節ケア。専門外顧問でも指導可能な具体的動作説明付き。
```

## 3. 部活動45分の安全管理フロー

* **開始時（怪我チェック）: 「今日どこか痛い人？」と挙手確認。軽度の違和感がある生徒は別メニューへ。
* **メニューの可視化: スマホで出力したメニューをホワイトボードに貼り、生徒自身にタイムキーパーを任せる。
* **定時完全撤収: 終了10分前に片付けに入り、暗闇での居残り練習をゼロにして下校。

## 4. やってはいけないNG指導と現場のリカバリー策

* **やってはいけないNG指導：暗闇の中で長距離走を延々と走らせる**  
  日没後の暗いグラウンドや学校周辺の道路を生徒に走らせるのは、段差での足首捻挫や自転車・歩行者との接触事故の危険が極めて高く、学校の安全配慮義務違反に問われます。必ず照明の届く範囲で活動してください。

* **現場のリカバリー策：生徒主体で進める「メニューリーダー制」**  
  顧問がつきっきりで笛を吹くのではなく、AIが作ったメニュー表を部長・副部長に渡し、生徒が主導でサーキットを回す形にします。顧問は全体を見守り、体調管理と安全確認に専念できます。
