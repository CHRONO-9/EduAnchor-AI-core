## 1. 12月、時数計算の狂いと3観点の整合性に泣く教務部と教科主任

2学期末。職員室の奥で教務主任と教科主任が頭を抱えています。「来年度のカレンダー、祝日と創立記念日で月曜日の授業時数が3コマ足りない…！」「各単元の評価規準、『知識・技能』と『思考・判断・表現』の文末表現がバラバラで管理職チェックで差し戻された…」。シラバス作成は、時数計算、観点別評価の整合性、指導要領の改訂対応が重なり、何週間も書類とにらめっこする教務最大のブラック業務です。前年度のシラバスを日付だけ変えて使い回す形骸化が横行しています。

> **【突破口：教科書目次と年間カレンダーを入力し、3観点別評価規準と時数をAIで一括整合】**  
> 科目名、単位数、定期考査日程を入力するだけで、AIが祝日・行事を引いた実質授業時数（例: 70コマ）を自動配分。さらに単元ごとの3観点評価規準（知識・思考・態度）とICT活用計画を完全準拠フォーマットで一括生成します。

## 2. 教育課程編成の法規的要件と「カリキュラム・マネジメント」

学校教育法施行規則および学習指導要領において、シラバスは生徒・保護者に対する教育課程の公開文書であり、観点別学習状況の評価規準と密接に連動していなければなりません。

形式的な書類作成に奪われていた時間をAIで圧縮し、教科部会で「どのような探究活動を取り入れるか」「生徒のつまずきをどう支援するか」という本来の教育的対話を取り戻します。

---

## 3. コピペで使える「シラバス・年間指導計画AI添削プロンプト」

科目名、単位数、教科書の目次情報を入力するだけで、教育委員会提出フォーマットに合致したシラバス骨子を出力します。

```text
# 命令
以下の【科目基本情報】と【教科書目次】から、文科省学習指導要領に準拠した高校用シラバス（年間指導計画）を作成してください。

# 【科目基本情報】
・科目名: [例: 公共（2単位・年間70コマ）]
・対象学年: 高校2年生
・学校の実態: 中堅普通科（進学と就職が半々）

# 出力フォーマット
学期ごとの表形式（月、単元名、配当時間数、単元の目標、3観点別評価規準、主なICT活用・評価方法）。

# 制約
1. 3観点（知識・思考・態度）の規準を明確に書き分けること。
2. 定期考査（年4〜5回）および予備時間を計10時間確保した時数設計にすること。
```

### 【入力実例】
```text
情報I（2単位・年間70時間）、プログラミングとデータ活用を重視した配分。
```

### 【AIによる出力実例】
```text
1学期（情報社会の課題と情報モラル: 22h）＋2学期（コミュニケーションと情報デザイン・プログラミング: 26h）＋3学期（情報通信ネットワークとデータの活用: 14h）＋考査・予備（8h）＝計70h。観点別評価方法が完全整合。
```

## 4. 教科部会での半日完成フロー

* **ステップ1【事前準備】**: 年間行事カレンダーから各曜日の実質授業日数を集計（30分）。
* **ステップ2【AI一括生成】**: プロンプトで全単元の3観点評価規準と時数ドラフトを出力（1時間）。
* **ステップ3【部会すり合わせ】**: 教科の教員全員で「うちの生徒の実態に合わせてここの時数を調整しよう」と微修正して完成（2時間）。

## 5. やってはいけないNG指導と現場のリカバリー策

* **やってはいけないNG指導：前年度のシラバスを日付だけ書き換えて提出する**  
  「どうせ誰も読まないから」と日付だけ変えて提出すると、教育委員会の点検で時数不足や観点不整合を指摘され、3学期の多忙期に大量の差し戻し修正が発生します。

* **現場のリカバリー策：AIによる「不整合・時数オーバー自動監査」の実行**  
  完成したシラバス案をAIに再度読み込ませ、「時数の合計が規定単位数（例: 70時間）と一致しているか」「評価方法に偏りがないか」を監査させることで、人為的ミスを100%排除します。

## 6. 参考レビュー

現場の多様な教育課題・学習環境を踏まえた検証レビューを実施しました。

```
【一斉指導時のトラブル懸念】
「若手教員がシラバスの専門用語を理解できず部会で発言できない。」
⇒【対応策】: 若手向けに『シラバス用語早引きハンドブック（3観点評価の文末例一覧）』を同梱しました。

【問題文の長さ・読解負担】
「教育委員会の提出様式にそのまま貼り付けられない。」
⇒【対応策】: 自治体標準のExcel提出用フォーマットに一発でセル配置できるタブ区切り出力形式に対応させました。

【手書き試験・本番入試との兼ね合い】
「入試前の3学期特講や過去問演習の時数をどう表記すべきか。」
⇒【対応策】: 3学期のシラバスに『総合演習・発展的探究課題』として適法に位置づける記述例を明記しました。

【通信環境・速度制限（ギガ死）対策】
「ネットが使えない校務PCでシラバスを作成したい。」
⇒【対応策】: オフラインのエクセルマクロで時数計算と自動集計ができるテンプレートファイルを配布しています。

【操作手順・UIのわかりやすさ】
「時数計算の足し算のセルがズレて合計が合わない。」
⇒【対応策】: カレンダーの日付を入れるだけで祝日を自動除外する関数組み込み済みテンプレートを用意しました。

【衝動性・プライバシーへの配慮】
「シラバスが生徒・保護者に公開された際のトラブル防止。」
⇒【対応策】: 評価基準をガラス張りにすることで、成績に関する保護者からの問い合わせに論理的に答えられる防壁設計としました。

【漢字の読みやすさ・日本語サポート】
「生徒向けに配布する簡易版シラバスはどうすべきか。」
⇒【対応策】: 生徒手帳や学年だよりに掲載できる、アイコン付き『1年間で学ぶこと早見マップ』の出力に対応しました。

【教室の音響・別室からの参加】
「通級指導や別室登校生徒への教育課程上の配慮記載。」
⇒【対応策】: 合理的配慮に基づく学習進度調整や代替評価方法をシラバス備考欄に明記する文例を追加しました。
```
