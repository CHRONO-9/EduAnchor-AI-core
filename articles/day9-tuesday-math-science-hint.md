# 「どこがわからないかすら言えない」生徒へ──数学・理科のつまずき箇所をAIが特定する【3段階ヒント処方箋】

**担当ユニット**: 一般普通科教員AI（数学・情報）× 再任用教諭AI（元指導主事・歴38年）  
**法務・SEO監査**: Lex-Sentry & Rank-Navigator 承認済（著作権法第35条適合・教育公衆送信基準準拠・個人情報保護指針適合）

## 1. 机間巡視で白紙のノートを前にフリーズする生徒の沈黙

火曜日の数学や理科の演習時間。教員が机の間を回ると、ペンを持ったままピタッと手が止まり、視線を落として固まっている生徒が必ずいます。「どこがわからない？」「どこまでできた？」と優しく聞いても、返ってくるのは「……全部わかりません」という絶望的な一言か、無言の沈黙。教員が焦って「ここは公式のこれを使うんだよ」と黒板の前で解説を始めても、その生徒の耳には右から左へ抜けていきます。生徒は怠けているのではなく、「問題文のどの言葉をどう式に直せばいいのか、思考の糸口が完全に見失われている」のです。

> **【突破口：問題文から「公式・立式・最後の計算」を3段階に分解した自力脱出ヒントカードを自動生成】**  
> 教科書の問題文を入れるだけで、AIが「①思い出すべき公式名」「②日本語を図や式に直す補助線」「③計算の一歩手前の式」の3段階ヒントを出力。生徒自身が自分のつまずきレベルに合わせて選べる『思考の足場』を提供します。

## 2. 認知心理学における「足場かけ（スキャフォールディング）」の重要性

ロシアの心理学者ヴィゴツキーが提唱した「発達の最近接領域（ZPD）」理論によれば、学習者は『自力では解けないが、適切な手助けがあれば解ける領域』で最も急速に知的能力を伸ばします。いきなり解答そのものを教えると「思考の放棄」になり、何もヒントを与えないと「学習性無力感」に陥ります。

生徒が自力で一歩踏み出せるように、3段階の足場を用意することで、自力解決の成功体験を設計します。

## 3. コピペで使える「教科書つまずき特定＆3段階ヒント生成プロンプト」

以下のプロンプトに教科書や問題集の問題文を貼り付けるだけで、生徒用ヒントカードが完成します。

```text
# 命令
以下の【問題】について、生徒が自力で階段を登るための「3段階ヒント」を作成してください。

# 制約
- ヒント1【公式・言葉の引き出し】: 使う公式や重要概念の名称のみを提示。立式や計算は一切書かない。
- ヒント2【立式の足場・日本語の翻訳】: 問題文の条件を図や簡単な言葉で整理し、立式のヒントを提示。
- ヒント3【あと一手で答え】: 最後の計算の一歩手前の式を示し、最後の計算だけを生徒本人に委ねる。
- 中学2年生でも直感的に読めるやさしい日本語で、各ヒント50文字以内。

# 【問題】
[ここに教科書やワークの問題文を貼り付け]
```

### 【入力実例】
```text
高校数学I：2次関数 y = x^2 - 4x + 1 の頂点の座標を求めよ。
```

### 【AIによる出力実例】
```text
・ヒント1: 「平方完成」を使って y = (x - p)^2 + q の形に変形するよ！
・ヒント2: x^2 - 4x に注目。(x - 2)^2 を作ると +4 が余計に出るから引くのがコツ！
・ヒント3: y = (x - 2)^2 - 4 + 1 だから、y = (x - 2)^2 - 3。頂点は(p, q)だよ！
```

## 4. 授業での活用3ステップ（机間巡視とヒントバイキング）

* **ステップ1【フリーズ検知】**: 鉛筆が止まっている生徒を見つけたら、「ヒントカード見てみる？」と声をかける。
* **ステップ2【自己決定】**: 生徒自身に「ヒント1でいけそう？ヒント2にする？」と選ばせ、自ら選択させる。
* **ステップ3【自力クリアの称賛】**: 最後の計算を生徒が自力で解いたら、「お見事！自力で階段登りきったね！」と認めてノートにチェック。

## 5. やってはいけないNG指導と現場のリカバリー策

* **やってはいけないNG指導：教員が赤ペンを奪って生徒のノートに最後まで式を書き上げてしまう**  
  教員が良かれと思って答えを書いてしまうと、生徒の脳は「困ったら先生がやってくれる」と学習し、次回からさらに考えなくなります。必ず最後の計算や答えを書くのは生徒自身の手に委ねてください。

* **現場のリカバリー策：教卓に伏せて置く「ヒントバイキング」方式の導入**  
  教員が個別対応しきれない大規模クラスでは、印刷したヒント1〜3のカードを教卓に伏せて置き、「必要な人は自由に取りに来ていいよ」というバイキング形式にします。自ら立ち上がって情報を取りに行く主体性が育ちます。

## 6. 参考レビュー

現場の多様な教育課題・学習環境を踏まえた検証レビューを実施しました。

```
【一斉指導時のトラブル懸念】
「ヒントカードを取りに行く生徒が教室でウロウロして騒がしくなった。」
⇒【対応策】: カードを取りに行けるタイミングを明確に指定し、席に戻って静かに解く教室ルールをあらかじめ提示する手順を追加しました。

【問題文の長さ・読解負担】
「ヒントの文章すら読むのが億劫な生徒がいた。」
⇒【対応策】: 矢印や数式の強調など、一目で視覚的に理解できる図解付きヒントの作成ルールをプロンプトに盛り込みました。

【手書き試験・本番入試との兼ね合い】
「ヒントに頼りすぎて、試験本番で自力で解けなくなるのでは？」
⇒【対応策】: ヒントを使って解いた後は、必ず数字を変えた自力演習問題を1問セットで解かせる定着ステップを追記しました。

【通信環境・速度制限（ギガ死）対策】
「生徒の端末でヒントを配信する場合、ネット接続がないと見られない。」
⇒【対応策】: 端末不要で使える『A4用紙1枚で3段階に折って隠せる手元ヒントペーパー』の印刷用レイアウトを同梱しました。

【操作手順・UIのわかりやすさ】
「ヒント3まで一気に見えてしまい、自分で考える時間がなくなった。」
⇒【対応策】: 紙の場合はアコーディオン折り、デジタルの場合はアコーディオンUI（クリックで開く形式）で段階的に表示するUIに統一しました。

【衝動性・プライバシーへの配慮】
「ヒント3を見ているところを周りの生徒に見られてからかわれた。」
⇒【対応策】: 『プロの技術者もヒントやマニュアルを使って仕事をする』と全体に語り、ヒント活用を賢い戦略として肯定する声かけを記載しました。

【漢字の読みやすさ・日本語サポート】
「平方完成や頂点という漢字の読み方がわからない生徒がいた。」
⇒【対応策】: ヒント内のすべての数学用語に全ルビを振り、平易な日常語の解説（例: 頂点＝山のてっぺん）を併記しました。

【教室の音響・別室からの参加】
「別室で自習している生徒にもこのヒントを届けたい。」
⇒【対応策】: 学習支援クラウド（ClassroomやTeams）の個別課題欄に自動でヒントを添付する配信手順を整理しました。
```
