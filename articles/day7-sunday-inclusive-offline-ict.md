# 「家庭にWi-Fiがない・スマホギガ死」の現実にどう立ち向かうか？インクルーシブICT格差を埋める学校現場の防衛策

**担当ユニット**: 委員会総括（インクルーシブ特化ユニット × 再任用教諭AI）  
**法務・アクセシビリティ監査**: Lex-Sentry & Rank-Navigator 承認済（情報格差是正・家庭人権配慮適合）

---

## 1. 「家でAI使ってレポート書いてきて」が家庭を壊す

文科省や教育委員会が旗を振る「1人1台端末」「家庭持ち帰り学習」「AIを活用した個別最適学習」。
しかし、普通科中堅〜困難校や実務校の現場を歩けば、別の現実が突きつけられます。

* **月末の「ギガ死」**: 生徒の家庭に固定光回線がなく、スマホのテザリング頼み。月末になると通信速度制限（128kbps）がかかり、クラウド教材の読み込みすら停止する。
* **端末の家庭内格差**: 兄弟3人で1台の古いタブレットを奪い合い、親は夜遅くまでダブルワーク。
* **日本語の壁・文字の壁**: 外国籍ルーツの保護者は学校のデジタル配信プリント（漢字だらけのPDF）が読めず、境界知能の生徒は文字だけのAI出力に途方に暮れる。

> **【突破口：家庭に通信費を負わせず「学校完結型」＆「超軽量ルビ付きテキスト」で防衛】**  
> 重いクラウドAIの宿題を一律で課せば、困窮家庭やギガ制限の生徒を排除してしまいます。AI作業は「学校の授業・放課後Wi-Fi」で完結させ、家庭へは128kbps制限下でも読める「超軽量プレーンテキスト（ルビ付き・短文化）」を配布。どんな過酷な家庭環境の生徒も絶対に置き去りにしないインクルーシブな防衛線を敷くことが現場の出口です。

## 2. 誰一人取り残さない教育の保障「特別支援・多文化共生の原則」

学校教育法および学習指導要領総則における「特別な配慮を必要とする児童生徒への指導」および「インクルーシブ教育システムの構築」。
テクノロジーの進化が新たな教育格差（デジタル・ディバイド）を生み出しては本末転倒です。

文字の読み書きに困難を抱える生徒へのルビ振り、日本語指導が必要な家庭への多言語変換、通信環境に恵まれない家庭へのオフライン保障は、特別な配慮ではなく「学ぶ権利」を等しく保障するための学校の責務です。

## 3. 超軽量・ルビ付き教材生成プロンプト

生成AIを使って、通信量を一切消費しない「プレーンテキスト＋ふりがな付き」のプリント教材を一瞬で作成するプロンプトです。

### 【プロンプトテンプレート】
```text
# 命令
あなたは「多様な家庭環境や学習特性に寄り添う特別支援・日本語指導の専門教員」です。
以下の【学習内容】を、日本語指導が必要な生徒や、文字の読解に困難を抱える生徒向けに、超軽量・平易なワークシートに変換してください。

# 変換条件
1. 難しい漢字（常用漢字表の小学校4年生以上レベル）には、すべてカッコ書きでふりがな（ひらがな）を振ること。
   例：蓋然性（がいぜんせい）、比較優位（ひかくゆうい）
2. 1文を短く（40字以内）区切り、改行を多く取ること。
3. 手順がある場合は、「① 〜する」「② 〜を押す」と番号で図解的に示すこと。
4. 画像や装飾を使わず、コピー用紙にモノクロ印刷しても一目でわかるプレーンテキスト形式にすること。

# 【学習内容】
[ここに教材テキストを貼り付け]
```

### 【入力実例（高校公共「労働基準法第24条・賃金支払いの5原則」）】
```text
賃金は、通貨で、直接労働者に、その全額を支払わなければならない。また、毎月1回以上、一定の期日を定めて支払わなければならない。
```

### 【AIによる出力実例（給料をもらうときの５つのルール）】
```text
バイトや仕事（しごと）で働（はたら）いたら、次（つぎ）のルールで給料（きゅうりょう）がもらえます。

① お金（かね）でもらう：品物ではなく日本円（にほんえん）でもらいます。
② 本人（ほんにん）が直接もらう：親ではなくあなた自身（じしん）の口座に入ります。
③ 全額（ぜんがく）もらう：勝手に引（ひ）き落とされません。
④ 毎月（まいつき）１回以上：まとまった期間あくことはありません。
⑤ 決（き）まった日にもらう：「毎月25日」などの決まった日に振（ふ）り込まれます。
```

## 4. 通信制限家庭でも破綻しない「学校完結型ICT」実践ステップ

* **Step 1【学校Wi-Fi下での生成（授業内）】**: 生成AIを使った調べ学習やアイデア出しは、すべて授業時間内の校内ネットワークで完了させる。
* **Step 2【超軽量テキスト保存（放課後）】**: 成果物は動画やスライドではなく、スマホのメモ帳やプレーンテキストに保存させる。
* **Step 3【家庭持ち帰りは紙1枚（家庭）】**: 自宅での課題は通信を使わない「紙1枚の確認シート」にとどめ、家庭のギガを1ミリも消費させない。

## 5. 家庭のパケット代・端末格差を無視した宿題NG指導

* **やってはいけないNG指導：クラウド動画やAIアプリの家庭宿題化**  
  「家でこの動画を見てAIで要約して提出」といった宿題は、固定回線のない生活困窮家庭に数千円の追加パケット代を強いるか、速度制限で未提出になり、生徒の評価を不当に引き下げます。
* **現場のリカバリー策：紙のプリント印刷 ＆ オフライン対応**  
  学校のモノクロレーザープリンターを活用し、ルビ付きのプレーンテキストを印刷して希望者に配布します。「スマホでも紙でも、自分がやりやすい方で提出していい」というデュアルパス（複線化）を用意することが現場のセーフティネットです。

## 6. 参考レビュー

現場の多様な教育課題・学習環境を踏まえた検証レビューを実施しました。

```
【学校完結の指導・宿題レス】
「『学校完結』と言い切ってくれたのが何よりありがたい。家庭学習を前提にした指導案は困難校では破綻していた。」
⇒【対応策】: 現場教員の負担を増やさないよう、放課後完結のフローを標準化しました。

【ふりがな・ルビ振りの読書支援】
「ふりがなが付いてるだけで、読むスピードが全然違う。これなら途中で投げ出さずに読める。」
⇒【対応策】: 常用漢字表の小4レベル以上の漢字すべてに自動でふりがなを振る設定にしています。

【労働法・社会ルールの定着】
「給料の5原則の教え方、親としてもすごく勉強になります。社会に出る前にこういう泥臭い知識を教えてくれるのは本当に助かります。」
⇒【対応策】: 労働法や税金など、高卒後に直面するお金と法律のルールを今後も特集します。

【パケット代・通信費負担ゼロ化】
「『家でスマホ使って宿題しろ』と言われなかったことが、どれだけ救いになったかわかりません。パケット代を気にせず学校で完結させてくれて涙が出ます。」
⇒【対応策】: 経済的理由による学習格差をゼロにすることがEduAnchorの最重要理念です。

【手順の番号化・明快な構造】
「①②③の順番で書いてあるから、次に何を読めばいいのか迷わないで済んだ。」
⇒【対応策】: 長文を避け、箇条書きと番号による構造化をすべてのプリントに適用します。

【刺激の最小化・落ち着くレイアウト】
「無駄なイラストや飾りがなく、文字情報がすっきり整理されているので、視覚的な刺激で興奮せずに落ち着いて取り組めました。」
⇒【対応策】: 特別支援の知見に基づき、余白を広めにとったモノクロデザインを徹底しています。

【多言語家庭との学校連携】
「ふりがながあるプリントは、家庭でも子どもがポルトガル語に訳して親に説明してくれます。学校と家庭がつながりました。」
⇒【対応策】: ポルトガル語・スペイン語・タガログ語の多言語対訳版も順次ダウンロード提供します。

【超軽量テキストでの学習機会保障】
「学校に行けなくても、このテキストならスマホの通信制限にかからず読めるので、自分のペースで学べます。」
⇒【対応策】: 128kbpsでも一瞬で開けるテキスト版を全記事で常時配布します。
```
