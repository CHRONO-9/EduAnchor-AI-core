## 1. 採点業務で教員が最も消耗する「2大ボトルネック」

教員の週末を奪う採点業務の正体は、以下の2つです。
1. **記述問題の採点基準ブレ**: 1枚目と100枚目で「この部分点は○か×か」の判定が揺れ、何度も前の答案を見返して時間を浪費する。
2. **手計算による集計ミス・二重チェック**: 大問ごとの得点加算、観点別評価の比率計算、電卓での検算に全体の40%の時間が溶けている。
これらはすべて『明確な採点ルーブリック』と『関数の自動集計』で機械化・半減できます。

## 2. 記述の採点ブレをゼロにする「3点刻みルーブリック」プロンプト

問題文と模範解答を入力するだけで、教員全員で共有できる客観的な採点基準表を出力します。

### 【記述採点ルーブリック作成プロンプト】
```text
# 命令
以下の【記述問題】と【模範解答（配点10点）】から、採点基準がブレないための「減点方式ルーブリック（10点・7点・4点・0点）」を作成してください。

# 【記述問題】
[問題文を貼り付け]

# 【模範解答と必須キーワード】
[模範解答と、必ず含めるべきキーワード2〜3個]

# ルーブリック出力条件
・10点（満点）: 必須キーワードがすべて含まれ、因果関係が論理的に成立している。
・7点（部分点高）: キーワードは網羅されているが、説明の順序や表現が不十分。
・4点（部分点低）: キーワードが1つ欠けている、または主語・述語のねじれがある。
・0点: 論点が的外れ、または白紙。
```

### 【入力実例】
```text
高校現代文：傍線部「近代の宿痾」とはどういうことか、50字以内で説明せよ。（配点10点）
```

### 【AIによる出力実例】
```text
10点: 「科学技術の過信」と「人間疎外」の両語を含み50字以内。7点: 片方の語のみ含む。4点: 本文の抜き出しのみでまとめ不足。0点: まったく異なる論述。採点時の迷いが完全消滅。
```

## 3. 答案採点の効率化3ステップ

* **大問ごとの横通し採点: 1人ずつ1枚すべて採点するのではなく、「全クラスの大問1だけ」「大問2だけ」と横通しで採点（判断速度が3倍に）。
* **得点の一括入力: スプレッドシートの専用フォーマットに大問ごとの得点をテンキー入力。
* **関数による自動判定: 合計点・観点別（知識・思考・態度）・赤点（平均点×0.4未満）が自動算出され、成績会議用資料が一発完成。

## 4. やってはいけないNG指導と現場のリカバリー策

* **やってはいけないNG指導：採点基準を途中で変えて前の答案を直さない**  
  採点の途中で「やっぱりこの書き方も○にしよう」と基準を緩め、それ以前に採点した答案を遡って修正しないと、生徒から「同じこと書いているのにあいつは○で俺は減点された」とクレームになり、信頼が失墜します。

* **現場のリカバリー策：迷った答案は「保留ボックス」へ即退避**  
  部分点をつけるか迷う答案は、その場で悩まず付箋を貼って「保留トレイ」に分け、全生徒の採点が一通り終わった最後にまとめて見比べることで、リズムを崩さず最短時間で基準を統一できます。
