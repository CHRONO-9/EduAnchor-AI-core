# 冬休みの宿題コピペを無力化する！身近な生活と結びつける【自分事化ミッション型課題】生成術

## 1. 検索してもAIに聞いても答えが出ない課題の共通点

生徒が課題をコピペするのは、その課題が「誰が解いても同じ答えになる調べ学習」だからです。
「日本の少子高齢化についてまとめよ」と出せばAIが一瞬で完璧なレポートを書きます。
しかし、**「あなたの自宅の冷蔵庫にある食材の原産国を3つ調べ、世界地図に矢印を引け」「家族に『仕事で一番気をつけている安全ルール』をインタビューせよ」**という課題なら、AIは生徒の家の冷蔵庫の中身も家族の言葉も知らないため、コピペが完全に不可能になります。

---

## 2. 教科別「自分事化ミッション」自動生成プロンプト

教科名と学習単元を入力するだけで、生徒が思わず家族や友達を巻き込みたくなる体験型ミッションを生成します。

### 【自分事化ミッション生成プロンプト】
```text
# 命令
以下の【教科・単元】について、AIやネット検索での丸写しが不可能な、冬休み用の「自分事化ミッション型課題」を3パターン作成してください。

# 【教科・単元】
[例: 家庭科（食生活と家計） / 商業（流通とマーケティング） / 理科（熱とエネルギー）]

# ミッション設計のルール
1. 生徒の「家庭・近所のコンビニやスーパー・自分のスマホ」を調査フィールドにすること。
2. 提出物は長文ではなく、「写真1枚＋手書きメモ3行」で完了できる軽量設計。
3. 家族や地域の人と1分間の会話が発生する要素を盛り込むこと。
```

### 【入力実例】
```text
家庭科：消費生活と契約・食生活。
```

### 【AIによる出力実例】
```text
ミッション1: 「近所のスーパーとコンビニで同じペットボトル緑茶の値段を比べ、なぜ価格差があるのか店内の陳列を観察して手書きメモせよ。」ミッション2: 「自宅の1週間のレシートを3枚集め、軽減税率（8%）と標準税率（10%）の品目を色分けせよ。」
```

## 3. 冬休み前の配布と年明けの回収・共有

* **冬休み前最後の授業: ミッション一覧シートを配布。「この中から好きなものを1つ選んで写真を撮ってきて！」と説明。
* **冬休み中: スマホで写真を撮影し、指定のシートに印刷または手書きメモを添付。
* **3学期最初の授業: クラスの前後4人グループで写真を持ち寄り、「うちの冷蔵庫こんなのあった」「これ面白かった」と5分間シェア。

## 4. やってはいけないNG指導と現場のリカバリー策

* **やってはいけないNG指導：分厚い問題集を1冊丸ごと宿題にする**  
  50ページの分厚い問題集を丸ごと課すと、生徒は年末年始に答えを写す作業に追われ、勉強嫌いが加速します。宿題は量を絞り、「自分で発見した喜び」を感じられるスモールミッションにする方が学習効果は圧倒的に高くなります。

* **現場のリカバリー策：写真が撮れない・家庭環境に配慮した「学校代替ミッション」**  
  家庭の事情で自宅での調査が難しい生徒のために、「冬休み明けの登校途中の電柱や標識を観察する」「学校の図書室の雑誌を調べる」などの代替選択肢をあらかじめ用意し、プライバシーと家庭環境に配慮します。
