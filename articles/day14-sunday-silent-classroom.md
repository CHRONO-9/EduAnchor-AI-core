# 「教室に入れない」生徒の学びを止めない──保健室登校・別室登校をつなぐ【サイレントオンライン教室】設計

**法務・SEO監査**: Lex-Sentry & Rank-Navigator 承認済（著作権法第35条適合・教育公衆送信基準準拠・個人情報保護指針適合）

## 1. 「声を出さなくていい・顔を出さなくていい」安心の学習空間

教室に入れない生徒の多くは、対人不安や感覚過敏、集団の視線に対する恐怖を抱えています。
「オンラインで授業を中継するからマイクをオンにして参加して」と迫ると、余計に拒絶されます。必要なのは、
- カメラOFF・マイクOFFが前提
- チャットやリアクションスタンプだけで意思表示
- 授業の板書スライドや要約テキストがリアルタイムで静かに届く
という『非同期・非接触型のサイレント接続』です。

---

## 2. 授業の要点を別室へ自動配信する「授業要約プロンプト」

教科担当教員が授業準備で使ったスライドやメモをAIに入力すると、別室の生徒が10分で読める「要点サマリーと今日の1問」が生成されます。

### 【サイレント授業サマリー生成プロンプト】
```text
# 命令
以下の【本日の授業内容】から、別室登校や自宅学習中の生徒が一人で安心して理解できる「やさしい授業ダイジェスト」を作成してください。

# 【本日の授業内容】
[単元名、黒板の板書計画、重要キーワードを貼り付け]

# 制約
1. 語り口は「〜だよ」「〜してみよう」と温かく、責めるニュアンスを完全に排除。
2. 5分で読めるように重要ポイントを3箇条に絞る。
3. 「今日の一歩チャレンジ」として、教科書の指定ページを見るだけで解ける確認クイズを1問だけ作成。
```

### 【入力実例】
```text
高校日本史：江戸幕府の成立と幕藩体制（親藩・譜代・外様の配置）。
```

### 【AIによる出力実例】
```text
「今日は家康がどうやって日本を治めたかを勉強したよ！ポイントは①大名を3グループに分けたこと②江戸の近くには信頼できる仲間を置いたこと③遠くには昔のライバルを置いたこと。Q: 江戸から遠い場所に置かれた大名を何と呼ぶ？（ヒント: 教科書p.112の太文字）」
```

## 3. 担任・養護教諭・別室担当の連携ステップ

* **朝の受け入れ: 保健室・別室で生徒の体調を確認し、Google Classroom等の専用スレッドを静かに開かせる。
* **自立学習（20〜30分）: 生徒は自分のペースでAIサマリーを読み、確認クイズにチャットで回答。
* **スタンプ承認: 担任や教科担当が空き時間に「読んだよ！ナイスチャレンジ！」とスタンプを1つ押すだけで、生徒は『自分は忘れられていない』と実感。

## 4. やってはいけないNG指導と現場のリカバリー策

* **やってはいけないNG指導：「早く教室に戻ろうね」と毎回プレッシャーをかける**  
  「いつ教室に戻れそう？」という善意の声かけが、生徒にとっては最も重い刃になります。教室復帰を急かすのではなく、「別室でも学びが続いている事実」を肯定し、出席認定や評価につなげることが最優先です。

* **現場のリカバリー策：出席扱い要件を満たす学習記録ログの自動保存**  
  文科省の「不登校児童生徒へのICTを活用した出席扱い」通知に基づき、生徒が回答したFormsやチャットログを週単位でPDF保存し、校長決裁用の学習実績シートとして整える運用を定型化します。
