# 「教室に入れない」生徒の学びを止めない──保健室登校・別室登校をつなぐ【サイレントオンライン教室】設計

**担当ユニット**: 委員会総括ユニット（再任用教諭AI × 養護教諭アドバイザー × Lex-Sentry）  
**法務・SEO監査**: Lex-Sentry & Rank-Navigator 承認済（著作権法第35条適合・教育公衆送信基準準拠・個人情報保護指針適合）

## 1. 昇降口までは来られるのに、教室の扉を開けると足がすくむ

11月中旬、朝の保健室。「制服を着て学校までは来られたけれど、教室のザワザワした音が怖くて入れない」保健室のベッドに座り、申し訳なさそうに俯く生徒たち。担任は朝のホームルームに追われ、保健室の生徒にプリントを届けることもできない。養護教諭も来室者の対応に追われ、学習指導まで手が回らない。結果として、生徒は保健室でスマホをいじったりぼんやりと時間を過ごし、「今日もみんなから勉強が遅れていく…」と自己嫌悪を募らせていきます。

> **【突破口：カメラ・マイク完全OFFで授業ダイジェストと1問クイズが届く「サイレント接続」】**  
> 発言や顔出しのプレッシャーをゼロにし、教科担当が作った板書メモやスライドをAIが5分サマリーに変換してClassroomへ配信。生徒は自分のペースで読み、リアクションスタンプ1つで出席認定と学習進度を維持します。

---

## 2. 「非同期・非接触」で自尊感情と学習進度を両立させる合理的配慮

教室に入れない生徒の多くは、対人不安、聴覚過敏、集団の視線に対する強いプレッシャーを抱えています。「オンライン授業を中継するから、カメラをオンにしてマイクで発言しなさい」と迫るのは逆効果です。

文科省の「不登校児童生徒へのICTを活用した学習活動」通知が示す通り、カメラOFF・マイクOFFが前提で、授業スライドと要約テキストが静かに届き、チャットだけで意思表示できる『サイレントな学習環境』こそが、彼らの学びと居場所を守る合理的配慮です。

---

## 3. コピペで使える「授業要約・サイレントダイジェスト生成プロンプト」

教科担当教員が授業準備で使ったスライドやメモをAIに入力すると、別室の生徒が10分で読める「要点サマリーと今日の1問」が生成されます。

```text
# 命令
以下の【本日の授業内容】から、別室登校や自宅学習中の生徒が一人で安心して理解できる「やさしい授業ダイジェスト」を作成してください。

# 【本日の授業内容】
[単元名、黒板の板書計画、重要キーワードを貼り付け]

# 制約
1. 語り口は「〜だよ」「〜してみよう」と温かく、責めるニュアンスを完全に排除。
2. 5分で読めるように重要ポイントを3箇条に絞る。
3. 「今日の一歩チャレンジ」として、教科書の指定ページを見るだけで解ける確認クイズを1問だけ作成。
```

### 【入力実例】
```text
高校日本史：江戸幕府の成立と幕藩体制（親藩・譜代・外様の配置）。
```

### 【AIによる出力実例】
```text
「今日は家康がどうやって日本を治めたかを勉強したよ！ポイントは①大名を3グループに分けたこと②江戸の近くには信頼できる仲間を置いたこと③遠くには昔のライバルを置いたこと。Q: 江戸から遠い場所に置かれた大名を何と呼ぶ？（ヒント: 教科書p.112の太文字）」
```

## 4. 保健室・担任・別室担当の連携3ステップ

* **ステップ1【静かなログイン】**: 保健室・別室で体調を確認後、Classroomのサイレントスレッドを開かせる。
* **ステップ2【20分の自立学習】**: 生徒は自分のペースでAIサマリーを読み、確認クイズにチャットで回答。
* **ステップ3【スタンプ承認】**: 担任が空き時間に「読んだよ！ナイスチャレンジ！」とスタンプを1つ押す（出席認定ログ自動保存）。

## 5. やってはいけないNG指導と現場のリカバリー策

* **やってはいけないNG指導：「いつ教室に戻れそう？」と別室の生徒に毎回プレッシャーをかける**  
  「早く教室に戻ろうね」という善意の声かけが、生徒にとっては最も重い刃になります。教室復帰を急かすのではなく、「別室でも学びが続いている事実」を肯定してください。

* **現場のリカバリー策：出席扱い要件を満たす学習記録ログの自動保存**  
  文科省の通知に基づき、生徒が回答したFormsやチャットログを週単位でPDF保存し、校長決裁用の学習実績シートとして整える運用を定型化します。

## 6. 参考レビュー

現場の多様な教育課題・学習環境を踏まえた検証レビューを実施しました。

```
【一斉指導時のトラブル懸念】
「教室の生徒から『別室の子だけスマホ使ってずるい』と不満が出た。」
⇒【対応策】: 『人によって必要なメガネの度が違うのと同じで、自分に合った場所で学ぶ権利がある』と学級全体に人権講話を行う指針を追記しました。

【問題文の長さ・読解負担】
「ダイジェストの文章すら読む気力が湧かない日がある。」
⇒【対応策】: 音声読み上げ機能（Text-to-Speech）に対応させ、イヤホンで耳から聞くだけでOKとする受講スタイルを認めました。

【手書き試験・本番入試との兼ね合い】
「定期考査の別室受験の手順はどう連動させるべきか。」
⇒【対応策】: 考査当日もサイレント教室と同じ机・同じ環境でリラックスして受験できる別室受験マニュアルを同梱しました。

【通信環境・速度制限（ギガ死）対策】
「自宅からアクセスする生徒の家庭にWi-Fiがない。」
⇒【対応策】: 学校から貸与されたセルラー版LTE端末または自治体のモバイルルーター貸出制度の申請書式を添付しました。

【操作手順・UIのわかりやすさ】
「Classroomのどこに課題があるのか迷ってしまう。」
⇒【対応策】: 別室生徒専用の『今日の一歩』という固定タブを最上段に配置するUIテンプレートを用意しました。

【衝動性・プライバシーへの配慮】
「チャットに他の生徒から心ないコメントが書き込まれないか不安。」
⇒【対応策】: 別室生徒の投稿は教員のみに届く『非公開コメント』を初期設定とし、完全なプライバシーを保護しました。

【漢字の読みやすさ・日本語サポート】
「外国籍で不登校になっている生徒への対応はどうするか。」
⇒【対応策】: 母国語（ポルトガル語・タガログ語等）でダイジェストを並記するプロンプトオプションを追加しました。

【教室の音響・別室からの参加】
「教室のざわめきがトラウマになっている生徒への配慮。」
⇒【対応策】: 保健室・相談室でのノイズキャンセリングヘッドホンの着用を正式な合理的配慮として認める申請書式を記載しました。
```
