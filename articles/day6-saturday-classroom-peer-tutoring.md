# 「進路が決まった生徒」と「焦る生徒」が同居する11月の教室マネジメント──次期指導要領の“協働的な学び”を建前で終わらせない処方箋

## 1. 11月の高3教室を襲う「見えない亀裂」

10月末から11月にかけて、高校3年生の教室には深刻な分断が生まれます。
一方は、9月・10月で早々に就職内定や指定校推薦の内定を勝ち取り、緊張の糸が切れて授業中に私語やお菓子をつまみ始める生徒たち。
もう一方は、これから11月・12月の総合型選抜や年明けの一般入試、国公立・共通テストを控え、ピリピリと張り詰めた表情で教科書を睨みつける生徒たち。

「早く決まったやつは静かにしてろよ！」「なんでそんなにカリカリしてんの？」
この空気感の放置は、最悪の場合、学級崩壊や進路決定者の停学処分、受験生のメンタル崩壊を引き起こします。

> **【突破口：内定組を「お客様」にせず、AIルーブリックを持たせた「ピア・チューター」へ任命】**  
> 進路が決まった生徒への単なる叱責は反発を生むだけです。彼らは厳しい選考を突破した貴重な経験者。AIが生成した「客観的な面接評価ルーブリック」を渡し、これから面接を受ける仲間の模擬面接官役（ピア・チューター）に任命します。お友達ごっこを防ぐ厳格な判定シートを持たせることで、内定組の自負心を刺激し、クラス全体の士気を高める出口を切り拓きます。

## 2. 協働的な学びの具現化「教え合い・支え合いの学級文化」

次期学習指導要領や中央教育審議会の答申で見据えられている「個別最適な学びと協働的な学びの一体的な充実」。進路が決まった生徒を単なる「自習・放置」にするのではなく、仲間のキャリア支援者として位置づけることは、まさに生きた協働の学びです。

他者の面接を客観的に観察し、評価基準に照らして建設的なフィードバックを行う経験は、内定組自身の社会人基礎力（傾聴力・批判的思考力・他者への助言力）を飛躍的に高めます。

## 3. 内定組に渡す「AI模擬面接ルーブリック評価表」

| チェック項目 | 合格基準（〇） | 改善アドバイス（×） |
| :--- | :--- | :--- |
| **① 最初の挨拶・姿勢** | 扉を開けて目を見て「失礼します」と一礼できている | 声が小さい、礼をしながら喋っている |
| **② 結論ファースト** | 「私の長所は〜です」と最初の1文で言い切れている | 「えーと、部活でですね…」と前置きが長い |
| **③ 具体的なエピソード** | 自分の失敗や苦労した事実が1つ入っている | 抽象的で「頑張りました」しか伝わらない |
| **④ 退室の所作** | 「ありがとうございました」と会釈して静かに扉を閉めた | 気が抜けてため息をつきながら扉を閉めた |

### 【業種別ルーブリック自動生成プロンプト】
```text
# 命令
以下の【生徒の志望分野・業種】に合わせて、高校生が友達同士で判定できる「模擬面接ルーブリック評価表（4項目）」を作成してください。

# 制約
1. 専門用語を使わず、「〇：できていること」「×：直すべきポイント」を平易な言葉で対比すること。
2. 現場企業が最重要視する行動規範（安全、報告、挨拶等）を必ず1項目含めること。

# 【生徒の志望分野・業種】
[ここに志望業種を記入（例：自動車製造、看護・医療、食品スーパーレジ接客 等）]
```

### 【入力実例】
```text
工業科・自動車工場ライン製造職志望
```

### 【AIによる出力実例（重点項目抜粋）】
```markdown
【項目：安全確認・ルール遵守】
〇（合格基準）：実習での指差し呼称や手順遵守の具体例を話せている。
×（改善点）　：「慣れたらスピード優先」など安全確認を軽視する発言がある。
```

## 4. ピア・チューター制度を成功させる教室運営4ステップ

* **Step 1【任命とリスペクト（HR5分）】**: 「先に合格した君たちはクラスの誇りであり先輩だ。仲間を勝たせる面接官になってくれ」と公に任命。
* **Step 2【ルーブリック講習（10分）】**: 評価シートを渡し、「良いところを1つ言ってから改善点を言う（サンドイッチ話法）」を徹底指導。
* **Step 3【ペア模擬面接（20分）】**: 1回5分×4交代。タイマーを鳴らしながら真剣勝負で模擬面接を実施。
* **Step 4【教員の称賛と感謝（5分）】**: 「面接官のアドバイスが的確だった。全員で合格をつかみ取ろう」と学級を一体化。

## 5. 生徒間カースト・マウント・いじめを防ぐペアリングNG集

* **やってはいけないNG指導：仲良しグループ同士でペアを組ませること**  
  仲良し同士で組ませると「私語・じゃれ合い」に発展するか、力関係（スクールカースト）がある場合に内定組が生徒へマウントをとっていじめの火種になります。
* **現場のリカバリー策：機械的シャッフル ＆ 「サンドイッチ話法」カンペ**  
  ペアは出席番号順やくじ引きなどの機械的シャッフルで組み、普段あまり話さない関係性を意図的につくります。また、評価シートの下部に「まず褒める⇒改善点を言う」の定型カンペを印刷しておくことで、トゲのある発言を未然に防止してください。

## 6. 参考レビュー

現場の多様な教育課題・学習環境を踏まえた検証レビューを実施しました。

```
【人間関係の上下・マウント防止】
「内定組に役割を与えるのは賛成。ただし、生徒同士の人間関係の上下（カースト）がある場合、いじめやマウントに発展しないよう教員のペア組み配慮が必須だ。」
⇒【対応策】: 仲良しグループを崩し、中立的なペアを機械的に組む「席替えシャッフルツール」の活用法を追記しました。

【緊張緩和とリラックス練習】
「先生に面接練習されると緊張して声が出ないけど、先に合格した友達が相手なら練習しやすいかも。」
⇒【対応策】: 友達同士の緊張緩和を活かしつつ、客観的なルーブリックで質を保ちます。

【授業規律と緊張感の維持】
「進路が決まったからといって、授業中におしゃべりして他の子の邪魔をすることだけは絶対に許せません。この制度でクラスが引き締まるなら応援します。」
⇒【対応策】: 内定組に責任と役割を持たせることで、授業妨害を未然に防止します。

【合格体験と知恵の共有】
「就職試験を一足先に突破した生徒の知恵を、これから受ける生徒にシェアできる仕組みは素晴らしい助け合いだと思います。」
⇒【対応策】: 「経験の共有」が最も効果的なピア・ラーニングとなります。

【チェックシートの平易さ】
「チェックシートに〇をつけるだけなら、自分でも面接官役のお手伝いができそうです。」
⇒【対応策】: 直感的な3択（〇/△/×）形式で誰でも判定できるシートに設計しています。

【言葉遣い・前向きな声かけ】
「衝動的に『今のダメ！下手くそ！』と相手を傷つける言葉を言ってしまわないよう、ポジティブな言い回しの台本が必要です。」
⇒【対応策】: 「まず良いところを1つ褒めてから改善点を言う」サンドイッチ話法のカンペカードをシートに追加しました。

【面接作法・所作の体得】
「文化の違いで面接の礼儀作法（お辞儀の角度や入退室）がわからない生徒にとって、友達の実演を見られるのは一番の勉強になります。」
⇒【対応策】: 視覚的に入退室の所作を学べるようイラスト付きマニュアルを付属しました。

【オンライン・ハイブリッド参加】
「教室の張り詰めた空気感が苦手で教室に入れない時期ですが、オンラインでペアを組んで面接練習ができるなら参加してみたいです。」
⇒【対応策】: Google Meet等のブレイクアウトルームでのオンラインピア面接手順も解説しています。
```
