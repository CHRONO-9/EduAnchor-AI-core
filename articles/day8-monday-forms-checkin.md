# 【コピペで即稼働】週明けの遅刻・体調不良・前時理解度を3分で可視化する「Forms×スプレッドシート」週初めチェックイン

**法務・SEO監査**: Lex-Sentry & Rank-Navigator 承認済（著作権法第35条適合・教育公衆送信基準準拠・個人情報保護指針適合）

## 1. 月曜朝の「誰がついてこられていないか」を3分で炙り出す

出欠確認で名前を呼ぶだけの時間に教員のエネルギーを浪費してはいけません。生徒が着席した瞬間に黒板またはプロジェクターのQRコードを読み込ませ、以下の3問に回答させます。
1. 今日の体調・メンタル（5段階アイコン）
2. 前回の重要用語（1問・直感選択）
3. 今日の単元で「ここが一番不安」なこと（自由記述・任意）
教員の手元の端末には、条件付き書式で「赤（体調不安）」「黄（前時不理解）」が即座に色分けされ、誰に個別声かけが必要かが一目瞭然になります。

## 2. Google Forms / MS Forms用コピペ質問セット

以下の質問文をFormsにコピペするだけで、3分チェックインフォームが完成します。

### 【Forms作成用テンプレート】
```text
[Q1 - 尺度] 今朝のエネルギー・集中度はどれくらい？（1: 限界・寝不足 〜 5: バッチリ集中できる）
[Q2 - 選択式] 前回習った「○○（単元キーワード）」の意味として最も近いものは？
  ・選択肢A（正解）
  ・選択肢B（よくある勘違い）
  ・選択肢C（前々回の内容）
  ・選択肢D（まったく覚えていない・正直に選択）
[Q3 - 短文] 授業が始まる前に先生に伝えておきたいこと・質問（スキップ可）
```

### 【入力実例】
```text
Google Formsで「スプレッドシートにリンク」を設定。Q1が「1または2」の場合はセルを薄い赤色、Q2が誤答の場合は薄い黄色にする「条件付き書式」を1回設定するだけ。
```

### 【AIによる出力実例】
```text
回答開始から90秒で回答率95%到達。教員は「今日は全体の3割が前回の公式でつまずいているから、導入の復習を3分延長しよう」「体調1のA君は後で保健室利用を確認しよう」と的確な戦術判断が可能に。
```

## 3. 授業開始3分タイムライン

* **0:00〜0:30【着席・Forms入力指示】: チャイムと同時にQRコードを投影。「出席代わりに回答して！」
* **0:30〜2:00【集計シート確認】: 教員は手元のタブレットでスプレッドシートのグラフと要注意セルを確認。
* **2:00〜3:00【全体フィードバック】: 「Q2の正答率は75%！間違えた人はここだけ要チェック」「体調しんどい人は無理せず合図してね」と宣言して本時へ。

## 4. やってはいけないNG指導と現場のリカバリー策

* **やってはいけないNG指導：体調不良や「覚えてない」の選択を怒る**  
  「なんで覚えてないんだ」「朝からだらけるな」と怒ると、生徒は嘘の回答（オール5・適当選択）をするようになり、フォームが死骸化します。正直に答えた生徒に「正直に教えてくれてありがとう、助かるよ」と伝えることがデータ活用の鉄則です。

* **現場のリカバリー策：端末忘れ・通信制限生徒用の「紙サイン」**  
  スマホを持参していない、またはギガ制限の生徒用には、名札カードの裏表（青/赤）を机の右上に置かせるアナログ運用を併用します。デジタルとアナログの複線化で一人も取り残しません。
