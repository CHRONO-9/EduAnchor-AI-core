# EduAnchor AI（エデュアンカー）

> **現場教員のための「AI×実践ICT」ナビゲーションプラットフォーム**  
> 日々の授業に悩む現場の教員へ照準。様々な生徒を抱える先生へ、毎日の授業に役立つ実践知とコピペ教材を日刊配信します。

---

## 🌟 プロジェクト概要

「EduAnchor AI」は、多忙を極める中学校・高等学校の教員を支援するために開発された教育実践知メディア・Webプラットフォームです。  
現場のリアルな困り感（週初めの授業の入り、教科書用語の噛み砕き、学級内の対立・萎縮、進路指導、作問・校務負担、インクルーシブ対応など）に寄り添い、**「5分でコピペ・即活用できる具体的な教材プロンプト・CSV・授業展開案」** を日刊形式で提供します。

- **公式ナビゲーター**: 水先 栞（みずさき しおり / Shiori Mizusaki, 27歳 元都立高校教員）
- **著作権法第35条 適合設計**: 学校教育利用における合法的かつ倫理的なガイドライン準拠

## 🚀 ローカルでのプレビュー

本プロジェクトは軽量な静的Webサイト（Tailwind CSS CDN + Vanilla JavaScript）として構築されており、特別なビルドツールなしで動作します。

任意のWebブラウザで直接 `index.html` を開くか、ローカルサーバーを起動してください：

```bash
# Pythonを使用する場合
python -m http.server 8000

# Node.js (npx) を使用する場合
npx serve .
```

ブラウザで `http://localhost:8000` にアクセスすると閲覧できます。
